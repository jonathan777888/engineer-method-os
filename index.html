Système de maîtrise par projets

Engineer Method OS

Transformer mes certificats IBM en compétences réellement utilisables, projets concrets et preuves GitHub.

Mission

Le certificat prouve qu'un parcours a été complété. Engineer Method OS mesure autre chose : ma capacité actuelle à comprendre, reconnaître, construire, corriger et intégrer une compétence dans un vrai projet.

Certificat → Cours → Concept → Compétence → Niveau → Exercice → Fonctionnalité → Projet → Preuve GitHub

Les 5 niveaux de maîtrise

Niveau 1 — Comprendre

Expliquer avec mes propres mots le rôle de la compétence et donner un exemple.

Niveau 2 — Reconnaître

Lire du code, une configuration ou un diagramme simple et identifier les éléments principaux.

Niveau 3 — Construire accompagné

Réaliser une petite fonctionnalité avec un guidage pas à pas tout en comprenant les étapes.

Niveau 4 — Modifier et corriger

Adapter une solution existante, diagnostiquer une erreur et effectuer une correction contrôlée.

Niveau 5 — Intégrer et démontrer

Relier la compétence au système complet, justifier les choix et produire une preuve professionnelle.

Les 14 blocs à maîtriser

On ne refait pas les cours certificat par certificat. On consolide les recouvrements puis on pratique chaque bloc dans des fonctionnalités réelles.

1. Software Engineering & SDLC

Problème, utilisateurs, exigences, architecture, cycle de vie et qualité.

2. Agile & Scrum

Backlog, user stories, priorité, sprint et amélioration continue.

3. Git & GitHub

Commits, branches, pull requests, historique, README et preuves.

4. Linux & Shell

Environnement d'exécution, fichiers, permissions, processus et automatisation.

5. HTML, CSS & JavaScript

Fondations du Web, DOM, événements, logique et appels asynchrones.

6. React & UI

Composants, props, state, hooks, formulaires et consommation d'API.

7. Node.js & Express

Backend JavaScript, routes, middleware, validation et API REST.

8. Python

Logique, scripts, automatisation, backend et applications IA.

9. Flask, Django & REST APIs

Services web Python, modèles, ORM, validation et APIs.

10. SQL, NoSQL & Data Modeling

Entités, relations, contraintes, CRUD, ORM et documents.

11. Cloud & Cloud Native

Hébergement, configuration, déploiement et séparation des composants.

12. Containers & Distributed Architecture

Docker, Kubernetes/OpenShift, microservices et serverless lorsque nécessaire.

13. Quality & Operations

Tests, CI/CD, sécurité, logs, métriques, traces et diagnostic.

14. Generative AI

Prompt engineering, modèles, contexte, validation et intégration IA contrôlée.

Apprendre par fonctionnalité

Pour chaque fonctionnalité : besoin utilisateur → compétences nécessaires → révision ciblée → construction guidée → tests → correction → documentation → commit GitHub → mise à jour du niveau.

Exemple : inscription d'un commerçant

Software Engineering : règles et parcours.

Données : User, Merchant et Store.

Backend : API d'inscription.

Frontend : formulaire et validation.

GitHub : branche, commit et preuve.

Qualité : tests, sécurité et gestion des erreurs.
